First job with new data: explore it and list what needs fixing.

Every transformer has the same three methods

fit()

Learns parameters from the training set.

transform()

Applies what was learned to any data.

fit_transform()

Both in one go. Faster and handier.

The rule

The same preprocessing, in the same order, goes on train, validation and test data. Fit on the training data only, then reuse the fitted object on the rest.

  • Cleaning and standardising: sklearn.preprocessing, sklearn.impute
  • Feature extraction: sklearn.feature_extraction
  • Feature reduction: sklearn.decomposition.PCA
  • Feature expansion: sklearn.kernel_approximation

Part 5

Missing values

The absence of data for a record.

Why it happens

Human error in entry or transfer. Sensor or machine failure. Corrupted data.

Why handle it

Some algorithms refuse NaN. Ignoring gaps can bias results.

Step one: find them

Missing values do not always look like NaN. Click through the views.

Try it

Spot the gaps

  • df.info() shows non-null counts per column.
  • df.isna().sum() counts real NaN only.
  • value_counts() or unique() catches strings like ?.
  • A seaborn heatmap of df.isna() shows the pattern at a glance.
df.replace(['?', '--', 'unknown'], np.nan, inplace=True)

Find it elsewhere

  • Weekday, month from a timestamp
  • Gender from a title like Mrs.
  • Public sources (movies, sports, cars)

  • A column that is mostly empty: drop the column

  • Mean, median, most frequent

Part 6

Outliers

A point that sits far from the rest.

Example

Your card is used in one country for months. Suddenly a payment appears abroad.

Three causes
  • Natural variability or measurement
  • Data entry errors
  • Novel or rare events
Why care

They can distort every statistic and model you build.

Handle with care

Remove a point if it is an error. If it is a real rare event, think before you delete it.

Spotting them

  • describe(): compare min, quartiles and max. A max far above the 75th percentile is a hint.
  • Box plot, histogram: one feature at a time.
  • Scatter plot: two features at once, to catch points that are odd only in combination.
  • Also in sklearn: IsolationForest, LocalOutlierFactor.
IQR method

IQR = Q3 − Q1. Anything outside the fences is an outlier.

lower = Q1 − 1.5 × IQR
upper = Q3 + 1.5 × IQR

Z-score method

How many standard deviations from the mean. Usually flag |z| > 3.

z = (x − mean) / std

Assumes the data is roughly normal.

Try it

Move the fences

inlieroutlierfence

Sample values, made up to look like a lab measurement with a few extreme readings.

What to do about them

Try it

Apply a treatment

One more option: if there are many far-away points, the data may hold two different groups. Model them separately.

q1, q3 = np.percentile(x, [25, 75])
iqr = q3 - q1
lower, upper = q1 - 1.5 * iqr, q3 + 1.5 * iqr
outliers = x[(x < lower) | (x > upper)]

z = (x - x.mean()) / x.std()
outliers = x[np.abs(z) > 3]
Is every outlier an error?

No. A trip abroad is a real transaction. Decide from the cause, not just from the number.

Feature scaling

Put every numeric feature on a comparable scale.

Loan example

Age runs 20 to 80. Income runs into lakhs. Left alone, income shouts and age is ignored.

The effect

The model may favour big numbers and misjudge which feature matters.

Same data, two answers

Houses described by age, area, bedrooms, stories, balconies. Who is the nearest neighbour of House 1?

Pitfalls

  • Scaling does not always help. Try it and check.
  • Scaled values lose real-world meaning. A negative age cannot be explained.
  • There is no single right scaler. Experiment and compare scores.
  • Leakage: learn the parameters from training data only.
Try it

Avoid data leakage

Train = 1, 2, 3, 4, 5. Test = 10, 12.

Which call is allowed on the test set?

Only transform(). Parameters were learned from the training set.

Do decision trees need scaling?

Rarely. They ask yes/no questions about one feature at a time.

Part 10

Feature selection

Drop features that do not help. Smaller data, cheaper training.

Filter

Score each feature on its own with a statistic.

VarianceThresholdSelectKBestSelectPercentileGenericUnivariateSelect
Wrapper

Use an actual estimator to judge features.

RFERFECVSelectFromModelSequentialFeatureSelector

Tree-based and kernel-based selection come in later weeks.

Filter: low variance

VarianceThreshold drops features whose variance is at or below a threshold. The default threshold of 0 removes constant features.

Try it

Slide the threshold

Filter: univariate selection

  • SelectKBest keeps the k top-scoring features.
  • SelectPercentile keeps the top percentage.
  • GenericUnivariateSelect picks the mode: 'percentile' (default), 'k_best', 'fpr', 'fdr', 'fwe'.
  • Related: SelectFpr (false positive rate), SelectFdr (false discovery rate), SelectFwe (family-wise error).
skb = SelectKBest(chi2, k=20)
X_new = skb.fit_transform(X, y)

gus = GenericUnivariateSelect(chi2, mode='k_best', param=20)
X_new = gus.fit_transform(X, y)
Try it

Which scoring function?

Watch out

A regression scorer on a classification problem gives useless results.

  • Mutual information: dependency between two variables. Never negative. 0 means independent.
  • Chi-square: non-negative features (booleans or counts) against a class label. Higher means more related.
  • F-statistics: classic test, for both tasks.
  • MI and chi-square suit sparse data.

Wrapper: RFE and RFECV

  • Fit an estimator on all features. Read the importances.
  • Remove the weakest. Repeat until you reach the number you want.
  • RFECV does this inside cross-validation, so it finds the number for you.
Try it

Eliminate one at a time

Wrapper: SelectFromModel

  • One fit. Keeps features whose importance beats a threshold.
  • Importance comes from coef_ or feature_importances_.
  • Threshold: a number, or 'mean', 'median', '0.1*mean'.
clf = LinearSVC(C=0.01, penalty="l1", dual=False).fit(X, y)
model = SelectFromModel(clf, prefit=True)
X_new = model.transform(X)    # keeps non-zero coefficients

Wrapper: sequential selection

  • Forward: start empty, add the feature that gives the best cross-validation score, repeat.
  • Backward: start full, remove features one by one.
  • Does not need coef_. Slower, since it fits many more models.
Try it

Forward or backward?

Chi-square needs what kind of feature values?

Non-negative ones, such as counts or booleans. It works for classification only.

Part 11

PCA

Fewer features, most of the information.

  • A linear method. It uses SVD to project data to fewer dimensions.
  • The first principal component points where the data varies most.
  • Each next one is at right angles to the earlier ones and captures less.
  • Keep the first k that cover the variance you want.
  • Scale first, or large-range features will lead.

Common slips

  • Calling fit on test data.
  • Deleting a real rare event because it looked odd.
  • Trusting isna() when missing values hide as strings.
  • Using a regression scorer for a classification target.
  • Treating one scaler as the answer for every dataset.
